## 1. 项目概述

### 1.1 什么是 Moltbot？

**Moltbot**（原名 Clawdbot）是一个运行在你自己设备上的*个人 AI 助手*。它通过一个统一的网关连接多个消息平台，让你在已经使用的频道上与 AI 助手交互。

### 1.2 核心特性

- **多频道支持**：WhatsApp、Telegram、Slack、Discord、Google Chat、Signal、iMessage、Microsoft Teams、Matrix、Zalo、Zalo Personal、WebChat
- **跨平台节点**：macOS、iOS、Android 应用支持
- **语音交互**：语音唤醒和对话模式
- **实时画布**：由 AI 驱动的视觉工作空间（A2UI）
- **本地优先**：数据隐私保护，所有数据存储在本地
- **可扩展性**：支持插件和技能系统

### 1.3 推荐配置

- **模型**：Anthropic Pro/Max (100/200) + Opus 4.5
- **原因**：长上下文强度和更好的提示注入抵抗能力

## 2. 核心概念

### 2.1 网关（Gateway）

网关是 Moltbot 的核心组件，是一个长期运行的进程，负责：
- 管理所有频道连接
- 提供 WebSocket 控制平面
- 处理会话和路由
- 执行工具和自动化任务

默认地址：`ws://127.0.0.1:18789`

### 2.2 会话（Session）

Moltbot 使用会话模型管理对话：
- **main**：直接聊天合并到共享的主会话
- **群组**：每个群组有独立的隔离会话
- **激活模式**：控制群组中机器人何时响应

### 2.3 节点（Node）

节点是连接到网关的客户端设备：
- **macOS 应用**：菜单栏控制、语音唤醒、画布渲染
- **iOS 节点**：画布表面、语音触发、相机
- **Android 节点**：画布、聊天、相机、屏幕捕获

### 2.4 工作区（Workspace）

- **默认路径**：`~/clawd`
- **内容**：代理配置、技能文件、提示模板
- **配置文件**：`AGENTS.md`、`SOUL.md`、`TOOLS.md`

### 2.5 技能（Skills）

技能是扩展代理功能的模块：
- **捆绑技能**：内置技能
- **管理技能**：用户安装的技能
- **工作区技能**：自定义技能

## 4. 安装指南

### 4.1 系统要求

- **Node.js**：>= 22.12.0
- **包管理器**：npm、pnpm 或 bun（推荐 pnpm）
- **操作系统**：
  - macOS（推荐）
  - Linux（服务器）
  - Windows（WSL2，强烈推荐）

### 4.2 安装方法

#### 方法一：安装脚本（推荐）

**Linux/macOS：**
```bash
curl -fsSL https://molt.bot/install.sh | bash
```

**Windows (PowerShell)：**
```powershell
iwr -useb https://molt.bot/install.ps1 | iex
```

#### 方法二：NPM 全局安装

```bash
npm install -g moltbot@latest
# 或
pnpm add -g moltbot@latest
```

#### 方法三：从源码构建（开发）

```bash
git clone https://github.com/moltbot/moltbot.git
cd moltbot
pnpm install
pnpm ui:build    # 首次运行时自动安装 UI 依赖
pnpm build
```

## 5. 快速入门

### 5.1 运行入门向导

```bash
moltbot onboard --install-daemon
```

向导会引导你完成：
- 模型/认证设置（OAuth 推荐）
- 网关配置
- 频道连接
- 配对默认值（安全 DM）
- 工作区引导 + 技能
- 可选后台服务安装

### 5.2 启动网关

如果安装了服务，网关会自动启动：

```bash
moltbot gateway status
```

手动运行（前台）：

```bash
moltbot gateway --port 18789 --verbose
```

### 5.3 访问控制面板

本地访问：`http://127.0.0.1:18789/`

### 5.4 配对第一个频道

**WhatsApp（QR 登录）：**
```bash
moltbot channels login
```
然后通过 WhatsApp → 设置 → 链接设备扫描二维码。

**Telegram/Discord：**
在向导中配置机器人令牌。

### 5.5 发送第一条消息

```bash
moltbot message send --target +1234567890 --message "Hello Moltbot"
```

或直接在已连接的频道中发送消息。

### 5.6 DM 安全配对

默认情况下，未知发送者会收到配对代码。批准配对：

```bash
moltbot pairing list whatsapp
moltbot pairing approve whatsapp <code>
```

## 6. 配置详解

### 6.1 配置文件位置

- **主配置**：`~/.clawdbot/moltbot.json`
- **认证文件**：`~/.clawdbot/credentials/`
- **会话存储**：`~/.clawdbot/sessions/`
- **工作区**：`~/clawd/`

### 6.2 核心配置项

```json
{
  "gateway": {
    "bind": "loopback",
    "port": 18789,
    "auth": {
      "mode": "token",
      "token": "your-token-here"
    },
    "tailscale": {
      "mode": "off"
    }
  },
  "agents": {
    "defaults": {
      "workspace": "~/clawd",
      "sandbox": {
        "mode": "non-main"
      }
    }
  },
  "routing": {
    "defaultAgent": "main"
  },
  "channels": {
    "whatsapp": {
      "enabled": true
    },
    "telegram": {
      "enabled": true
    }
  }
}
```

### 6.3 模型配置

支持多种模型提供商：
- **Anthropic**：Claude Pro/Max（推荐）
- **OpenAI**：ChatGPT/Codex
- 其他兼容 API

配置命令：
```bash
moltbot configure --section models
```

## 7. 频道设置

### 7.1 支持的频道

| 频道 | 协议 | 说明 |
|------|------|------|
| WhatsApp | Baileys (WhatsApp Web) | 最常用 |
| Telegram | Bot API (grammY) | 功能完整 |
| Discord | Bot API | 私信 + 服务器 |
| Slack | Bolt | 企业集成 |
| Signal | signal-cli | 隐私优先 |
| iMessage | imsg CLI | macOS 专用 |
| Google Chat | Chat API | G Suite 集成 |
| Microsoft Teams | 扩展 | 企业协作 |
| Matrix | 扩展 | 去中心化 |
| WebChat | 内置 | 浏览器界面 |

### 7.2 频道配置示例

**Telegram：**
```json
{
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "your-bot-token",
      "dm": {
        "policy": "pairing"
      }
    }
  }
}
```

**Discord：**
```json
{
  "channels": {
    "discord": {
      "enabled": true,
      "botToken": "your-bot-token",
      "clientId": "your-client-id",
      "dm": {
        "policy": "pairing"
      }
    }
  }
}
```

### 7.3 群组设置

群组默认基于提及激活，可切换：

- `/activation mention` - 仅在被提及时响应
- `/activation always` - 始终响应

## 8. 常用命令

### 8.1 网关管理

```bash
# 启动网关
moltbot gateway --port 18789

# 查看状态
moltbot gateway status

# 停止网关
moltbot gateway stop

# 重启网关
moltbot gateway restart
```

### 8.2 消息发送

```bash
# 发送消息
moltbot message send --target +1234567890 --message "Hello"

# 与助手对话
moltbot agent --message "帮我写个清单" --thinking high
```

### 8.3 频道管理

```bash
# 登录频道
moltbot channels login

# 查看频道状态
moltbot channels status

# 探测频道连接
moltbot channels status --probe
```

### 8.4 配置管理

```bash
# 设置配置
moltbot config set gateway.port 18789

# 获取配置
moltbot config get gateway.port

# 编辑配置
moltbot config edit
```

### 8.5 诊断命令

```bash
# 系统状态
moltbot status

# 健康检查
moltbot health

# 安全审计
moltbot security audit --deep

# 医生（诊断和修复）
moltbot doctor
```

### 8.6 配对管理

```bash
# 列出待批准配对
moltbot pairing list <channel>

# 批准配对
moltbot pairing approve <channel> <code>

# 拒绝配对
moltbot pairing reject <channel> <code>

# 移除配对
moltbot pairing remove <channel> <peer-id>
```

### 8.7 节点管理

```bash
# 列出节点
moltbot nodes list

# 节点状态
moltbot nodes status

# 调用节点
moltbot nodes invoke --node <node-id> --method <method>
```

## 9. 高级功能

### 9.1 语音唤醒和对话

**macOS/iOS/Android 支持：**

- **语音唤醒**：始终在线的语音监听
- **对话模式**：连续对话体验
- **TTS（文本转语音）**：ElevenLabs 集成

配置：
```bash
moltbot configure --section voice
```

### 9.2 实时画布（Canvas + A2UI）

由 AI 驱动的视觉工作空间：
- 动态内容渲染
- 交互式 UI 组件
- 实时更新

访问：`http://<gateway-host>:18793/__moltbot__/canvas/`

### 9.3 浏览器控制

专用的 moltbot Chrome/Chromium 浏览器：
- 快照和操作
- 配置文件管理
- CDP 控制

```bash
# 启动浏览器
moltbot browser start

# 浏览器快照
moltbot browser snapshot

# 浏览器操作
moltbot browser action <action>
```

### 9.4 Cron 和自动化

**定时任务：**
```bash
# 添加 cron 任务
moltbot cron add --schedule "0 9 * * *" --message "早报"

# 列出 cron 任务
moltbot cron list

# 删除 cron 任务
moltbot cron remove <id>
```

**Webhook：**
```bash
# 添加 webhook
moltbot webhook add --url <url> --events message,reaction
```

### 9.5 技能系统

**技能类型：**
- 捆绑技能（内置）
- 管理技能（用户安装）
- 工作区技能（`~/clawd/skills/`）

**技能安装：**
```bash
# 通过 ClawdHub 安装
moltbot skills install <skill-name>

# 列出技能
moltbot skills list

# 删除技能
moltbot skills remove <skill-name>
```

### 9.6 多代理路由

将不同的频道/账户路由到隔离的代理：

```json
{
  "routing": {
    "agents": {
      "main": {
        "workspace": "~/clawd"
      },
      "work": {
        "workspace": "~/clawd-work"
      }
    },
    "rules": [
      {
        "channel": "discord",
        "guildId": "work-guild",
        "agent": "work"
      }
    ]
  }
}
```

## 10. 安全配置

### 10.1 DM 访问策略

默认安全策略：**配对模式（pairing）**

```json
{
  "channels": {
    "whatsapp": {
      "dm": {
        "policy": "pairing"
      }
    },
    "telegram": {
      "dm": {
        "policy": "pairing",
        "allowFrom": []
      }
    }
  }
}
```

**开放访问（谨慎使用）：**
```json
{
  "dm": {
    "policy": "open",
    "allowFrom": ["*"]
  }
}
```

### 10.2 网关认证

**Token 认证（推荐）：**
```json
{
  "gateway": {
    "auth": {
      "mode": "token",
      "token": "your-secure-token"
    }
  }
}
```

**Tailscale 认证：**
```json
{
  "gateway": {
    "auth": {
      "mode": "tailscale",
      "allowTailscale": true
    }
  }
}
```

### 10.3 权限管理

**macOS 节点权限：**
- 屏幕录制
- 相机访问
- 通知
- 文件系统

**权限检查：**
```bash
moltbot doctor --permissions
```

## 11. 故障排除

### 11.1 常见问题

**网关无法启动：**
```bash
# 检查端口占用
lsof -i :18789

# 查看日志
moltbot logs tail
```

**频道连接失败：**
```bash
# 探测频道状态
moltbot channels status --probe

# 重新登录
moltbot channels login
```

**认证问题：**
```bash
# 检查认证状态
moltbot health

# 重新配置
moltbot configure --section models
```

### 11.2 诊断命令

```bash
# 全面诊断
moltbot doctor

# 深度状态
moltbot status --all

# 安全审计
moltbot security audit --deep
```

### 11.3 日志查看

```bash
# 查看日志
moltbot logs tail

# 按类别过滤
moltbot logs tail --category gateway

# macOS 日志
./scripts/clawlog.sh
```

## 12. 开发指南

### 12.1 开发环境

```bash
# 克隆仓库
git clone https://github.com/moltbot/moltbot.git
cd moltbot

# 安装依赖
pnpm install

# 构建 UI
pnpm ui:build

# 构建
pnpm build

# 开发运行（自动重载）
pnpm gateway:watch
```

### 12.2 测试

```bash
# 单元测试
pnpm test

# 覆盖率
pnpm test:coverage

# E2E 测试
pnpm test:e2e

# 实时测试（需要真实密钥）
CLAWDBOT_LIVE_TEST=1 pnpm test:live
```

### 12.3 代码检查

```bash
# Lint
pnpm lint

# 格式化
pnpm format

# 修复
pnpm lint:fix
```

### 12.4 插件开发

创建扩展频道：

```typescript
// extensions/my-channel/src/index.ts
import { Channel } from 'moltbot/plugin-sdk';

export class MyChannel extends Channel {
  async sendMessage(target: string, content: string) {
    // 实现发送逻辑
  }
}
```
