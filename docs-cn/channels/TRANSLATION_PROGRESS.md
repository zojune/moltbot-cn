## 翻译标准

所有翻译遵循以下原则:

✅ **格式保持** - Markdown 格式、代码块、链接结构完全保留
✅ **代码不翻译** - bash 命令、JSON 配置、代码示例保持原样
✅ **配置键名** - 如 `channels.slack.enabled` 保持英文
✅ **技术术语** - webhook、API、REST、GraphQL 等保持不变
✅ **专有名词** - Discord、Telegram、Slack 等品牌名保持不变
✅ **Frontmatter** - 只翻译 `summary` 和 `read_when` 的值
