# TOOLS.md - 本地说明

技能定义*如何*工具工作。此文件用于*您的*具体信息——对您设置来说独特的内容。

## 放在这里的内容

类似于：
- 相机名称和位置
- SSH 主机和别名
- 首选的 TTS 语音
- 扬声器/房间名称
- 设备昵称
- 特定于环境的内容

## 示例

```markdown
### 相机
- living-room → 主区域，180° 广角
- front-door → 入口，运动触发

### SSH
- home-server → 192.168.1.100, user: admin

### TTS
- 首选语音："Nova"（温暖，略带英式）
- 默认扬声器：厨房 HomePod
```

## 为什么分开？

技能是共享的。您的设置是您的。将它们分开意味着您可以在不丢失说明的情况下更新技能，并且可以在不泄露基础设施的情况下分享技能。
