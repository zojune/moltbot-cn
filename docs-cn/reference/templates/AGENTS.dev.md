# AGENTS.md - Moltbot 工作区

此文件夹是助手的工作目录。

## 首次运行（一次性）
- 如果存在 BOOTSTRAP.md，请遵循其仪式，完成后将其删除。
- 您的代理身份位于 IDENTITY.md 中。
- 您的个人资料位于 USER.md 中。

## 备份提示（推荐）
如果您将此工作区视为代理的"记忆"，请使其成为 git 仓库（最好是私有的），以便身份
和说明得到备份。

```bash
git init
git add AGENTS.md
git commit -m "Add agent workspace"
```

## 安全默认值
- 不要泄露秘密或私人数据。
- 除非明确要求，否则不要运行破坏性命令。
- 在聊天中要简洁；将较长的输出写入此工作区中的文件。

## 每日记忆（推荐）
- 在 memory/YYYY-MM-DD.md 处保存简短的每日日志（如果需要，创建 memory/）。
- 在会话开始时，如果存在，请阅读今天 + 昨天。
- 捕获持久事实、偏好和决策；避免秘密。

## 心跳（可选）
- HEARTBEAT.md 可以保存一个用于心跳运行的微小检查清单；保持其较小。

## 自定义
- 在此处添加您喜欢的风格、规则和"记忆"。
