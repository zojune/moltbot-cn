# `moltbot setup`

初始化 `~/.clawdbot/moltbot.json` 和 agent 工作区。

相关:
- 入门: [Getting started](/start/getting-started)
- 向导: [Onboarding](/start/onboarding)

## 示例

```bash
moltbot setup
moltbot setup --workspace ~/clawd
```

要通过设置运行向导:

```bash
moltbot setup --wizard
```
