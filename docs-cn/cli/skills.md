# `moltbot skills`

检查技能(捆绑 + 工作区 + 托管覆盖)并查看符合条件与缺失要求的内容。

相关:
- 技能系统: [Skills](/tools/skills)
- 技能配置: [Skills config](/tools/skills-config)
- ClawdHub 安装: [ClawdHub](/tools/clawdhub)

## 命令

```bash
moltbot skills list
moltbot skills list --eligible
moltbot skills info <name>
moltbot skills check
```
